# Course Companion — визуальный прототип 0.1

Кликабельный прототип трёх экранов: библиотека → курс «Неделя агентов 2026» → лекция 1.2 Tools & MCP.
Статический сайт без сборки: `index.html`, `styles.css`, `js/`, `data/`, `assets/`.

Запуск локально: `python3 -m http.server 8765` в этой папке, затем http://127.0.0.1:8765/
(через `file://` данные лекции не загрузятся).

## Маршруты (hash-токены)

`#library`, `#course-shad`, `#lecture-tools-mcp`, разделы лекции: `#tools-mcp-video`,
`#tools-mcp-notes`, `#tools-mcp-code`, `#tools-mcp-codevideo`, `#tools-mcp-lab`.

## Что реальное, а что демо

| Реальное | Источник |
|---|---|
| Видео | YouTube `VctYHtCap3o`, встроенный плеер (IFrame API) |
| Транскрипт с таймкодами, 909 фрагментов | автосубтитры YouTube, `data/transcript.json` |
| 16 глав, привязки 17 из 18 слайдов | `data/chapters.json`, `data/slides.json` — по речи, кадры видео не сверялись |
| Слайды | `lecture_1_2_tools_mcp.pdf` → `assets/slides/` |
| Конспект | `~/career/learning/shad/notes/lecture_1_2_tools_mcp.md` → `data/notes.md` |
| Код в разборе, code-video и лаборатории | ноутбук лекции, ячейки 6, 19, 35 |

Демо (помечено в интерфейсе): прогресс и карточки других курсов, состояния сборки,
добавление курса, ответы чата, каталог лабораторий кроме L01. Лаборатория — учебная
симуляция в браузере; ключ идемпотентности — учебное дополнение, в ноутбуке его нет.

Подготовка данных (Codex) и её отчёт: `provenance/`.
