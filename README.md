# Course Companion — визуальный прототип 0.3

Кликабельный прототип трёх экранов: библиотека → курс «Неделя агентов 2026» → лекция 1.2 Tools & MCP.
Статический сайт без сборки: `index.html`, `styles.css`, `js/`, `data/`, `assets/`.

0.2 добавляет кастомизацию лекции (`js/custom.js`): действия с фрагментом, личные правки поверх
оригинала, карточки из чата и свои материалы, заявки на генерацию code-video и лабораторий.

0.3 улучшает чтение и работу на телефоне:

- Видео, конспект, код, анимация и лаборатория — отдельные режимы с сохранением позиции
  при переключении. Главы, транскрипт и слайды находятся в одной панели рядом с видео
  или сразу под ним. Описание лекции свёрнуто.
- Оглавление доступно через «Разделы» на любой ширине; выбранный режим виден в полосе
  навигации. В библиотеке боковая панель показывает курсы. На странице курса выделено
  продолжение обучения; готовность материалов раскрывается отдельно.
- На телефоне лаборатория начинается с выбора сценария, затем запуска и таблицы сравнения.
  Подробное состояние и журнал раскрываются. У анимации есть крупные индикаторы участников,
  отдельно открываемая полная схема и код.
- Чат занимает отдельную колонку на широком экране и полный экран на телефоне.
  Подсказки сворачиваются после первого вопроса. Закрытые панели исключены из Tab-навигации.
- Диалоги открываются с заголовка, удерживают фокус и возвращают его при закрытии
  (`js/ui.js`). План заявки показывает результат, цену и время до подробностей.
- Зона нажатия «+» — 44×44 px; выбранный фрагмент подсвечивается.

Запуск локально: `python3 -m http.server 8765` в этой папке, затем http://127.0.0.1:8765/
(через `file://` данные лекции не загрузятся).

## Проверка

Сервер должен быть запущен. Нужны Python, Playwright и Chromium:

```bash
CC_BASE_URL=http://127.0.0.1:8765/ uv run --with playwright python tests/ux-smoke.py
CC_BASE_URL=http://127.0.0.1:8765/ uv run --with playwright python tests/learning-flow.py
```

Если Chromium установлен отдельно, передайте его путь через `CC_CHROME`.
`ux-smoke.py` проверяет адаптивность и клавиатуру на 390/1024/1440 px;
`learning-flow.py` — переходы между материалами, сохранение позиции и личных правок,
чат, L01 и жизненный цикл L02 с перезагрузкой. Контексты браузера изолированы.
Снимки второго сценария сохраняются в `CC_SCREENSHOTS` (по умолчанию `/tmp/cc-ux-03`).
Воспроизведение YouTube на сервере может потребовать подтверждения «не бот».

## Итерация 0.2: кастомизация

- **Действия с фрагментом.** «+» у абзаца конспекта и транскрипта (на телефоне виден всегда) и то же
  меню при выделении текста: «Спросить в чате» (цитата со ссылкой на раздел или таймкод),
  «Объяснить проще», «Переписать по-своему» (только конспект), «Сделать сцену по этому».
- **Личная версия** заменяет абзац в чтении; оригинал можно показать рядом или вернуть.
- **Из чата в лекцию:** «+ Добавить в конспект» под ответом → карточка «Из чата» в конце раздела.
  В конце каждого раздела — «+ Свой материал» (ссылка, заметка, файл — файл не загружается).
- **Заявки:** план (пример, сценарии, параметры, источники, время, цена; Подтвердить / Изменить /
  Отменить) → заглушка в разделе со статусом → черновик (Принять / Переделать / Отклонить).
  Вкладка «Заявки» на странице курса: фильтр по статусу, бюджет, описание уведомлений Орио в Telegram.
  Сквозной пример — L02 «Частичный сбой транзакции» (§4, charge → reserve → delivery):
  черновик — рабочая мини-лаборатория с выбором места сбоя и компенсацией.
- **Обнаружимость:** «Заказать» у планируемых лабораторий, у пустых code-video/лабораторий в
  матрице готовности и в разделах конспекта без визуализации; «Сделать похожую» под L01;
  одно предложение агента в чате за обсуждение; одноразовая подсказка над конспектом.

Всё демо: состояние хранится в `localStorage` этого браузера («Сбросить демо-правки» в боковой
панели), ничего не генерируется, сроки заявок ускорены, пересказы «проще» и ответы подготовлены вручную.

Подготовка данных (Codex) и её отчёт: `provenance/`.


## Preview 0.4 — демо, не рабочее AI-приложение

**Маршруты:** `#library` — библиотека, `#lecture-tools-mcp` — ШАД (видео, код, лаборатория),
`#tools-mcp-lab` — проверка в лаборатории, `#physics` и `#physics-1` … `#physics-5` —
лекция «Законы Ньютона» с веб-оригиналом OpenStax и двумя задачами.

| Реализовано локально | Демо/ограничения |
|---|---|
| Сохраняемые заметки, статусы, карточка возвращения | `localStorage` только текущего браузера; прогресс «self» только после проверки |
| Ссылки на OpenStax §4.1–4.4, схема сил, задачи | PDF-страницы не проверены; обозначение «§», а не «стр.» |
| ШАД: lab L01 + code-video | Проверка текста по ключевым словам, не LLM |
| Вкладки «Проще», «Переписано», пример | До локального запуска Task 9 тексты помечены `[черновик]` |
| Генератор `tools/gen_demo_ai.py` | OpenRouter `google/gemini-3.7-flash`, `temperature=0.3`; ключ `OPENROUTER_API_KEY` |

Генератор намеренно **не запускается** в превью. Ручной запуск: `python tools/gen_demo_ai.py --only physics:2`
для пробной генерации или `python tools/gen_demo_ai.py` для полного набора. Стоимость берётся из `usage.cost`
ответа API, а не вычисляется по предположению. Журнал и сырые ответы — в игнорируемой папке
`provenance/demo-ai`. До генерации проверка ответов Task 9 **ожидаемо красная**.

Контент источника адаптирован для внутреннего использования; см. [условия OpenStax](https://openstax.org/books/physics/pages/preface).
Для запуска: `python3 -m http.server 8765` в корне проекта, затем http://127.0.0.1:8765/ .
Никаких push или merge в `main` для этого overlay не требуется.
