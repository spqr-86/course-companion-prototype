## 3. Лекция по физике без видео

**Тема [моё]:** «Законы Ньютона» (9 класс): короткая, задачи легко повторить с другими числами.
Риск по ревью: тема Петру знакома, придётся «играть школьника» — учесть при оценке (раздел 6).

**Источник [моё]:** OpenStax *Physics* (high school, CC BY), глава о силах и законах Ньютона.
Конспект на русском, ссылки ведут на фрагменты оригинала. Лицензию и номера страниц проверить
при сборке, атрибуция по требованиям CC BY.

**Что видит пользователь вместо видео [Argon]:** HTML-имитация страниц учебника — нужные
абзацы оригинала (англ.) с якорями и номером страницы, формулы простым HTML/CSS. Без pdf.js.
Клик по ссылке в конспекте прокручивает к абзацу и подсвечивает его; рядом с пересказом видна
цитата оригинала (проверка п. 6.5 MVP).

**Содержание лекции:**
- 4–5 разделов: сила и равнодействующая; первый закон; второй закон; третий закон; типичные
  ошибки (сила ≠ скорость, пары сил приложены к разным телам);
- в каждом разделе: справочный слой (конспект ИИ со ссылками), блок «Как я понял», 1 схема сил;
- в конце 2 задачи **[Argon]**: 1 качественная («почему пассажира бросает вперёд при торможении»)
  и 1 расчётная (F = ma с трением), у расчётной — похожая задача с другими числами.

## 4. Механики

1. **Два слоя.** У каждого раздела справочный слой и блок «Как я понял» (пусто, пишет
   пользователь). Пометки происхождения: «из источника» / «объяснение ИИ» / «моя заметка».
2. **Вкладки версий [Argon].** Над абзацем вкладки `[Оригинал] [Проще (ИИ)] [Переписано (ИИ)]
   [Моя версия]`; показываются только существующие. «Объяснить проще» и «Переписать» добавляют
   вкладку, оригинал не заменяется.
3. **Статусы.** У раздела: «видел» (дочитал/досмотрел), «разобрался с помощью», «воспроизвёл сам».
   Прогресс курса — только по третьему.
4. **Проверка «объясни без подсказки» — заглушка [Пётр].** Кнопка в конце раздела: конспект
   сворачивается, вопрос, поле ответа. Вердикт выдаёт правило в JS, а не модель: пусто или
   короче ~15 слов → «слишком коротко, раскрой …»; нет ключевых понятий раздела (2–4 на раздел,
   с синонимами) → «не хватает: …»; иначе → «зачтено» и статус «воспроизвёл сам». Плашка у
   вердикта: «Демо-проверка по ключевым словам, не ИИ». Кнопка «оспорить» → статус всё равно
   засчитывается с пометкой «засчитано по оспариванию».
5. **Задача с лестницей — только в физике [Argon].** Намёк → ссылка на место в конспекте →
   наводящий вопрос; «Показать решение» всегда доступна: сначала следующий шаг, затем полное
   решение; статус «решено с решением», потом похожая задача без подсказок. Ответ расчётной
   задачи сверяется по числу с допуском (заглушка, без модели). В ШАД задачи нет.
6. ~~Вход в курс «продолжить + проверка»~~ — убран из превью **[Argon]**. Вместо него — карточка
   возвращения без проверки (п. 4.8).
7. **Лаба L01 — режимы «Исследовать» / «Проверить себя» [GPT DR].** «Исследовать» — поведение 0.3,
   по умолчанию. «Проверить себя»: прогноз перед развилкой (сколько возвратов без ключа и с
   ключом) → прогон → объяснение расхождения (та же заглушка, что п. 4.4) → новое условие → статус
   «воспроизвёл сам» и блок «Мой вывод» под лабой. Предсказание — только перед содержательной
   развилкой, не перед каждым запуском. Code-video: один необязательный вопрос «где выполняется
   cancel_booking», ролик не блокирует.
8. **Карточка возвращения [GPT].** На главной вместо захардкоженного «Продолжить с 12:34»:
   что разбирал (последний раздел, лаба или задача), мой вывод или черновик «Как я понял»
   (первые строки), открытый вопрос — первый раздел без «воспроизвёл сам» или незавершённая
   проверка. Кнопка «Продолжить разбор» восстанавливает место, режим лабы и черновик. До первого
   действия карточка показывает «Начать» с онбординговыми кнопками.
9. **Три главных действия фрагмента [GPT].** В меню выделенного фрагмента сверху: «Объяснить»
   (бывш. «Объяснить проще»), «Показать на примере», «Проверить себя» (проверка раздела п. 4.4).
   «Переписать иначе», «Моя версия», «Спросить в чате» — во вторичной группе «Ещё».
   «Показать на примере» открывает лабу или code-video раздела, если есть, иначе — демо-пример ИИ
   под фрагментом. «Создать объяснение» (заявка) — в архиве.

**Демо-ответы ИИ [Argon]:** тексты «Объяснить проще», «Переписать» и ответы чата генерируются
целевой дешёвой моделью с первого дубля, без ручной редактуры. Модель, промпт и дата сохраняются
в `prototype/provenance/`. Модель выбрать при плане (кандидат — та, что планируется для MVP-0).

## 6. Как проверю готовность

**Технически:**
- Онбординг: первый вход показывает окно с плашкой демо, «Закрыть» работает, повторный вход не
  показывает, «Как это работает» открывает снова; кнопки ведут в нужную лекцию.
- Обе лекции открываются из библиотеки; ссылки физики прокручивают к абзацу оригинала.
- Сценарии: «Объяснить проще» → новая вкладка → возврат к оригиналу; «Как я понял» сохраняется
  после перезагрузки; заглушка проверки: короткий ответ → отказ, ответ с ключевыми словами →
  «воспроизвёл сам», «оспорить» → засчитано с пометкой; задача: подсказки → решение →
  «решено с решением» → похожая → «воспроизвёл сам»; заявки ШАД в архиве, лабы видимы; L01 в
  режиме «Проверить себя» проходит до «Мой вывод»; после reload карточка «Продолжить разбор»
  ведёт на последнее место с черновиком.
- `tests/ux-smoke.py` и `tests/learning-flow.py` проходят; новые сценарии добавлены туда же;
  ширины 390/1024/1440.
- Публикация: commit, push в `main` прототипа — только после «публикуй».

**Чек-лист решения для Петра [Argon]** (ответить текстом после прохождения превью):
1. Визуальный шум: раздел с пометками, вкладками, ссылками, «Как я понял» и проверкой — хочется
   ли уйти в чистый документ?
2. Трение ввода: напечатал ли ты хоть по одному осмысленному абзацу в «Как я понял» и в проверке?
   Сколько ушло на преодоление лени?
3. Честность прогресса: 0% при «видел» и «разобрался с помощью» мотивирует пройти проверку или
   раздражает?
4. Сверка с источником: удобно ли читать русский конспект и сверять подсвеченный английский абзац
   на 1024/1440?
5. Поправка на знакомый материал: что из ответов выше вызвано тем, что тема уже известна?
6. **Сценарий демо [GPT]:** открыл материал → нашёл непонятное место → «Показать на примере» →
   записал свой вывод → закрыл вкладку → открыл снова → «Продолжить разбор». Смог ли продолжить
   без повторного поиска? Понятно ли было, что сохранилось и где это найти?
7. Лаба в режиме «Проверить себя»: прогноз перед прогоном помог понять или мешал?

Если по 1–3 ответ негативный — MVP-0 в текущем дизайне не строим, сначала упрощаем механику.
